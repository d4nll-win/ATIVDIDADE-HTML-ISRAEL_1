# Atividade HTML

Projeto desenvolvido como atividade prática de HTML, com o objetivo de aplicar conceitos básicos de estruturação e criação de páginas web.

## Sobre o projeto

O projeto contém páginas desenvolvidas utilizando HTML, acompanhadas de imagens utilizadas na composição e apresentação do conteúdo.

## Estrutura

* `HTML/` — arquivos HTML do projeto
* `IMAGENS HOME/` — imagens utilizadas na página inicial
* `IMAGENS PAGE 2/` — imagens utilizadas na página 2
* `IMAGENS PAGE 3/` — imagens utilizadas na página 3
* `IMAGENS PAGE 4/` — imagens utilizadas na página 4

## Tecnologias utilizadas

* HTML5
* Git
* GitHub

## Objetivo

Praticar os fundamentos do desenvolvimento web utilizando HTML, incluindo a criação de páginas, utilização de imagens, links, textos, listas e outros elementos básicos.
